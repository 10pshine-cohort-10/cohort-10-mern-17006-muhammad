The backend now uses strict TypeScript instead of JavaScript. TypeScript checks the code for type mistakes before it runs, making changes easier to maintain and safer to build upon.

All five backend source files were converted to TypeScript. The project uses a strict tsconfig.json, including noUncheckedIndexedAccess, and keeps compiled JavaScript in backend/dist. The npm scripts use tsx watch for development, tsc for builds, node to run the compiled server, and tsc --noEmit for type checking.

The server now waits for its listening event before reporting successful startup. It also handles server errors, including port binding errors such as EADDRINUSE, logs the failure, and exits with status code 1 rather than reporting a false success.

Iteration 2 adds MongoDB and Mongoose support. The application now loads a MongoDB connection string from MONGODB_URI, waits for the database before starting the HTTP server, and logs database connection problems.

It also defines the User and Note data models. User records include a name, email, and password hash; the password hash is excluded from normal queries. Note records belong to a User and include a title and rich-text content. The Note model includes an index that makes it faster to retrieve a user's newest notes.

The application now recognizes MongoDB-specific problems. Invalid IDs become 400 Bad Request responses, invalid model fields become 400 responses with validation details, and duplicate records become 409 Conflict responses.
